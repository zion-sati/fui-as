# SelectionArea

```ts
import { SelectionArea } from "./Fui";
```

- **Constructor:** `new SelectionArea()`
- **Children:** `child(node)`, `children(nodes)`
- **Selection signal:** `selectedText` (`Signal<string>`)

`SelectionArea` enables cross-node selection behavior for child text content and updates `selectedText` as selection changes.
