# Form

```ts
import { Form } from "./Fui";
```

- **Constructor:** `new Form()`
- **Assign buttons:** `defaultBtn(button)`, `cancelBtn(button)`
- **Lifecycle:** `activate()`, `deactivate()`

While active, `Form` handles `Enter`/`Escape` globally for default/cancel press-release behavior.
