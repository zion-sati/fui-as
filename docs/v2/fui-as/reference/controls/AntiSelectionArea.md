# AntiSelectionArea

```ts
import { AntiSelectionArea } from "./Fui";
```

- **Constructor:** `new AntiSelectionArea()`

Use this as a selection barrier inside a `SelectionArea` when a subtree should not be aggregated into parent cross-selection behavior.
