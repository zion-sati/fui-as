# ScrollBar

```ts
import { Orientation, ScrollBar, ScrollBarVisibility } from "./Fui";
```

- **Constructor:** `new ScrollBar(scrollState, orientation = Orientation.Vertical)`
- **Style:** `trackWidth`, `thumbWidth`, `thumbMinHeight`, `trackColor`, `thumbColor`, `trackCornerRadius`, `thumbCornerRadius`
- **Render host:** `render(): FlexBox`
- **Lifecycle:** `dispose()`

`ScrollBarVisibility` is used by `ScrollBox` / `TextArea` to control chrome behavior (`Always`, `Auto`, `Never`).
